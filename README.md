# Nur - نور

Bilingual (Urdu/English) Islamic PWA. Single-file HTML5.

## Features
- Complete Quran (114 surahs) + Last Read bookmark
- Prayer times + Hijri date
- Tasbeeh counter with vibration
- 12 daily duas (Arabic + translation)
- Qibla direction (GPS compass)
- Urdu / English toggle
- Dark / Light theme

## APIs
- api.aladhan.com
- api.alquran.cloud
